# University Transport Management System

A C-based University Transport Management System for managing buses, routes, schedules, and student transport payments.

## Features

- Add, display, search, update, and delete bus information
- Manage weekly transport schedules
- Manage student transport payments
- Student payment verification
- Admin login and control panel
- User panel for students, teachers, and staff
- File handling for storing bus and payment information
- Uses singly linked lists for data management

## Technologies Used

- C Programming Language
- Structures
- Singly Linked Lists
- File Handling
- CRUD Operations
- Basic Authentication
